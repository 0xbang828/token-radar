Token Launch Radar

What a protocol with no token on record would be worth, if its record held

Each protocol is priced at its TVL times the market-cap-to-TVL multiple its own category has actually traded at, then adjusted for seven-day growth, how long it has run without a token, whether it is a launch candidate or a wrapped/staked/bridged product of a token that already trades, and how scarce pre-token TVL is. Every figure below comes from the sealed snapshot; nothing is hand-picked. An implied value is an estimate, not a price and not a promise that a token is issued.

The board is split in two, each half ranked on its own: launch candidates — no token on record and no parent product — and live-adjacent products, the wrapped, staked, bridged, exchange and versioned products of a token that already trades. A derivative product's multi-billion TVL is not evidence of a launch, so it no longer competes for a launch rank.

Live tokens — set aside, priced by the market

These protocols already record a token and a market cap, so their value is a fact rather than a model. Their mcap/TVL ratios are also the only evidence the model learns from, which is why they are shown here instead of being ranked against protocols still waiting on a launch.
