Token Launch Radar

What a protocol with no token on record would be worth, if its record held

Each protocol is priced from the three figures the brief names — its TVL, its seven-day growth and how long it has run with no token — by a law fitted on the protocols in this snapshot that already have a token and a TVL: mcap = exp(a + b × log(tvl) + c × growth + d × log(age)), every coefficient solved from the snapshot at run time. Because b is below one, the market-cap-to-TVL multiple is not a constant, so a row is priced against protocols its own size and its own trajectory, not against one number applied to all of them.

The board carries every pre-token protocol the snapshot records, split in two and each half ranked on its own: launch candidates — no token on record and no parent product — and live-adjacent products, the wrapped, staked, bridged, exchange and versioned products of a token that already trades. Each section is priced by its own fit. An implied value is an estimate, not a price and not a promise that a token is issued.

Live tokens — set aside, priced by the market

These protocols already record a token and a market cap, so their value is a fact rather than a model. Their mcap/TVL pairs are also the only evidence the model learns from — the power law is fitted on them, in two populations — which is why they are shown here instead of being ranked against protocols still waiting on a launch.
